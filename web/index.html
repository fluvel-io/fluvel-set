Installation help (Windows, macOS, Linux, Python)
Windows (installer or portable)

Fluvel Set is not code-signed yet, so Windows may show Windows protected your PC the first time you run it. This is expected.

  1. Click More info.
  2. Click Run anyway.

You only need to do this once. The portable version needs no installation: unzip it and run FluvelSet.exe.

macOS (DMG)
  1. Drag Fluvel Set to the Applications folder.
  2. Open Fluvel Set. macOS shows a warning and does not start it: this is expected, because the app is not notarized by Apple. Close the dialog.
  3. Open System Settings > Privacy & Security and scroll down to the Security section.
  4. Click Open Anyway next to Fluvel Set and enter your password.
  5. Open Fluvel Set again and confirm.

You only need to do this once. On macOS Sonoma or earlier, you can also right-click Fluvel Set and choose Open.

Linux (AppImage)

Make the file executable, then run it:

chmod +x FluvelSet-linux.AppImage
./FluvelSet-linux.AppImage

AppImages need FUSE 2. If the application does not start on Ubuntu or Debian, install it (sudo apt install libfuse2, or libfuse2t64 on Ubuntu 24.04), or run it without FUSE: 

./FluvelSet-linux.AppImage --appimage-extract-and-run

The AppImage uses the system C and C++ libraries, so it needs a recent distribution: glibc 2.39 or newer, for example Ubuntu 24.04, Debian 13 or Fedora 40 and later. On older systems, use the Flatpak.

Linux (Flatpak)

The bundle needs the KDE runtime from Flathub, which Flatpak installs for you if the Flathub remote is configured: 

flatpak remote-add --if-not-exists --user flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user FluvelSet-linux.flatpak
flatpak run io.github.fluvel_io.fluvel-set

The Flatpak runs on any distribution. This bundle is not updated automatically: download the new file to upgrade.

Python (pip)

Fluvel Set is also available as a Python package, to script the processing of many images. Wheels are provided for Linux (x86_64, glibc 2.34 or newer), Windows (x64) and macOS 13+, for Python 3.11 to 3.14. Create a virtual environment first: 

# Linux / macOS
python3 -m venv .venv
source .venv/bin/activate

# Windows (PowerShell)
python -m venv .venv
.venv\Scripts\Activate.ps1

Then install the package:

pip install fluvel-set --find-links https://github.com/fluvel-io/fluvel-set/releases/expanded_assets/latest-python
pip install "fluvel-set[examples]"   # adds OpenCV, used by the example scripts

Check the installation and find out which code is running:

python -c "import fluvel; print(fluvel.__version__, fluvel.__commit__)"

fluvel.__commit__ is the commit the installed module was built from. The source of that exact version is at https://github.com/fluvel-io/fluvel-set/commit/<commit>. Note that it can be older than the commit shown at the top of the page, which is the one of the applications: the Python wheels are rebuilt only when the library or the bindings change.

The example scripts are in the examples folder of the repository. The commit and the checksum of every wheel are listed in BUILD_INFO-python.txt.

About Fluvel Set

Fluvel Set is a research-oriented image segmentation application designed for fast and efficient experimentation with level-set active contour methods.

It provides real-time image processing, video stream support, pre-processing tools and quantitative evaluation metrics for segmentation analysis.
