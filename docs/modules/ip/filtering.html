Image Filtering#

This module provides image preprocessing and enhancement algorithms used throughout Fluvel IP.

The filtering framework includes spatial and temporal smoothing filters, edge-preserving diffusion methods, morphological operators and reusable processing pipelines. These algorithms are commonly used to prepare images for segmentation and shape-analysis tasks.

References#

Pietro Perona and Jitendra Malik, Scale-Space and Edge Detection Using Anisotropic Diffusion, IEEE Transactions on Pattern Analysis and Machine Intelligence, 12(7):629–639, 1990.

Simon Perreault and Patrick Hébert, Median Filtering in Constant Time, IEEE Transactions on Image Processing, 16(9):2389–2394, 2007.

Marcel van Herk, A Fast Algorithm for Local Minimum and Maximum Filters on Rectangular and Octagonal Kernels, Pattern Recognition Letters, 13(7):517–521, 1992.

Related Components#

  • fluvel_ip::filter::TemporalMean

Smoothing#

Each filter is available as stateless functions, convenient for one-off use, and as a class that keeps its buffers between calls, which is faster when many images are filtered.

class TemporalMean#
#include <temporal_mean.hpp>

Adaptive temporal smoothing filter.

This filter performs temporal denoising by maintaining an exponentially weighted moving average (EWMA) of successive frames.

The smoothing strength is automatically adjusted according to the estimated scene motion and noise level:

  • static scenes are strongly averaged to reduce sensor noise,

  • moving scenes remain reactive to avoid motion blur and ghosting.

The implementation uses a continuous-time formulation, making the filter largely independent of the input frame rate.

Typical use cases:

  • video denoising,

  • low-light image stabilization,

  • temporal noise reduction in live acquisition pipelines.

template<bool IsMax>
void naiveMorpho(const ImageView &input, ImageOwner &output, int radius)#

Naive morphological filter (dilation or erosion).

This function applies a square structuring element of radius radius using a straightforward implementation:

  • If IsMax = true → dilation (max filter)

  • If IsMax = false → erosion (min filter)

The implementation iterates over all pixels in the neighborhood (O(N * k²)), making it suitable for:

  • small kernel sizes

  • fallback when optimized algorithms (e.g. van Herk) are not applicable

Border handling is performed using clamping (replication of edge pixels).

Note

Complexity is O(N * (2r+1)²).

Note

This implementation is typically used as a reference or fallback.

Template Parameters:

IsMax – Selects the operation:

  • true → dilation (max)

  • false → erosion (min)

Parameters:

  • input – Input image view.

  • output – Output image owner (must match input layout).

  • radius – Radius of the structuring element (kernel size = 2 * radius + 1).

template<bool IsMax>
void vanHerk(const ImageView &input, ImageOwner &output, int radius)#

Morphological filter using the Van Herk algorithm.

Computes grayscale dilation (max) or erosion (min) with a square structuring element of size (2 * radius + 1).

This implementation achieves O(N) complexity per row/column using a sliding-window monotonic deque.

The algorithm is applied in two separable passes:

  • horizontal

  • vertical

Template Parameters:

IsMax – If true computes dilation, otherwise erosion.

Parameters:

  • input – Input image.

  • output – Output image (must have same layout as input).

  • radius – Radius of the structuring element.

template<bool IsMax>
void vanHerkVertical(const ImageOwner &buffer, ImageOwner &output, int width, int height, int channels, int activeChannels, int radius, std::vector<int> &ring)#

Vertical pass of the Van Herk algorithm.

Same sliding window as the horizontal pass, along image columns.

Walking down a column touches one cache line per row, which is slow on large images. The columns are therefore processed by tiles: a tile is copied transposed (each column becomes a contiguous line), filtered, then copied back. The result is the same.

Template Parameters:

IsMax – If true computes dilation (max), otherwise erosion (min).

Parameters:

  • buffer – Intermediate buffer from horizontal pass.

  • output – Output image.

  • width – Image width.

  • height – Image height.

  • channels – Number of channels per pixel (1, 3 or 4).

  • activeChannels – Number of processed channels (1 or 3).

  • radius – Radius of the structuring element.

  • ring – Scratch buffer shared by all the calls.

void subtract(const ImageView &a, const ImageView &b, ImageOwner &out)#

Compute pixel-wise saturated difference between two images.

For each pixel and channel, computes:

out = max(0, a - b)

Both input images must have identical dimensions and format.

Note

Common uses include:

  • morphological white top-hat transforms

  • morphological gradients

  • directional image comparison

Note

For RGBA/BGRA images, the alpha channel is copied unchanged from the first operand.

Parameters:

  • a – First input image.

  • b – Second input image.

  • out – Output image (must match input layout or be reallocated accordingly).
